# __Calculadora Kotlin__

Este repositório é de uma calculadora básica e científica escrita
apenas em Kotlin e Jetpack Compose para a plataforma móvel Android.
Este foi o meu primeiro projeto de aplicação móvel feito durante o
bacharelado de Engenharia de Software.

Caracterísitcas
* Cálculo de raiz enésima;
* Cálculo de logaritmos de base **n** e logaritmando **m**;
* Cálculo de potência enésima (base **n**, expoente **m**);

Build (Compilação)
1. Clone o repositório: ```git clone https://github.com/Israel-Burlamaqui/calculadora-kotlin.git```

2. Abra o projeto no Android Studio (File->Open...->)
3. Pressione ``` Shift + F10 ``` para compilar
